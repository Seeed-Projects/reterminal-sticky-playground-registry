# Sticky Case Simple

A compact bumper case for reTerminal Sticky by Faulince Huang. It wraps the
edges of the device and leaves the screen, side button, and USB-C port open.

- STL file: <https://files.seeedstudio.com/wiki/reterminal_sticky/res/sticky_case_simple.stl>
- Author: [Faulince Huang](https://www.facebook.com/groups/2141790083310058/user/1030037078/)

The Registry stores the metadata and preview image for this design. The STL
file is hosted on the Seeed Studio wiki file server.
