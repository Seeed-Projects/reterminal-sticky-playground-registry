# Pregnancy-Journal

## What it is

孕期手帐是运行在 Seeed Studio reTerminal Sticky（一台小型磁吸电子纸设备）上的离线 孕期记录固件。它在 Sticky Core 硬件框架上提供孕周首页、体重记录、数胎动和设置。
