# Moments

## What it is

Context aware dashboards. Just like TRMNL, but dashboards update automatically based on context.

## Source

- Project: https://github.com/Makestreme/moments
- License: Apache-2.0

## Package

- Version: 1.0.0
- `bootloader.bin` at 0x0 (18720 bytes)
- `partitions.bin` at 0x8000 (3072 bytes)
- `boot_app0.bin` at 0xe000 (8192 bytes)
- `moments.bin` at 0x10000 (1820384 bytes)

Submitted by [Arpan](https://www.youtube.com/@makestreme).
