# Example Printable Design

Copy this directory to `integrations/<design-id>/`, then provide:

1. Complete metadata in `integration.json`.
2. A real photo of the printed design on reTerminal Sticky as `assets/preview`.
3. An HTTPS link to the files on Printables, MakerWorld, Thingiverse, or GitHub.
4. Author credit and the license used by the external design page.
5. Print settings and assembly notes in this README.

The Registry stores metadata and the preview image. Printable files stay on
the author's page.

Run `npm test` and `npm run validate` from the repository root before opening a
pull request.
