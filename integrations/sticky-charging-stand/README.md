# Sticky Charging Stand

A minimalist desk stand for reTerminal Sticky by ALXV Labs. The stand keeps the
device upright and routes a USB-C cable underneath so Sticky stays charged while
it is used as a desk display.

- Files and print profiles: <https://makerworld.com/en/models/3094593-seeed-studio-sticky-charging-stand>
- Author: [ALXV Labs](https://makerworld.com/en/models/3094593-seeed-studio-sticky-charging-stand)

The Registry stores the metadata and preview image for this design. The print
files stay on the author's MakerWorld page.
