# Sticky Table Stand

A desktop stand for reTerminal Sticky by Gokul. It holds the device at a
comfortable viewing angle for desk use.

- Files: <https://grabcad.com/library/table-stand-for-seeed-studio-sticky-1>
- Author: [Gokul](https://grabcad.com/library/table-stand-for-seeed-studio-sticky-1)

The Registry stores the metadata and preview image for this design. The CAD and
print files stay on the author's GrabCAD page.
