# reTerminal Sticky 3D Model

A community-made 3D model of the reTerminal Sticky enclosure by Hendra Kusumah,
published on Printables. Use it to check fit when designing cases, stands, and
mounts, or remix it into your own accessory.

- Files: <https://www.printables.com/model/1800955-seeed-studio-reterminal-sticky-3d-model>
- Author: [Hendra Kusumah](https://www.printables.com/@HendraKusuma_2346746)

The Registry stores the metadata and preview image for this design. The model
files stay on the author's Printables page.
