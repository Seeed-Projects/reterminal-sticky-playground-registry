# reTerminal Sticky 3D Model

The reference 3D model of the reTerminal Sticky enclosure, published on
Printables by Seeed Studio. Use it to check fit when designing cases, stands,
and mounts, or remix it into your own accessory.

- Files: <https://www.printables.com/model/1800955-seeed-studio-reterminal-sticky-3d-model>
- Author: [Seeed Studio](https://www.printables.com/@SeeedStudio)

The Registry stores the metadata and preview image for this design. The model
files stay on the Printables page.
